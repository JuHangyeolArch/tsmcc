** DONE IR 제네레이터개발
1) I/O 빌트인 생각
   - PUT, GET
   - 거의 대부분 하드웨어 의존적임 -> 함수 시작을 제외하고 라벨화 해놓고 코드 제네레이터가 생성
2) 함수, 함수호출, 변수, 레지스터, 상수, 브랜치 메모리
   - 함수 -> 시작, 프롤로그, 에필로그만 라벨로 명시해놓는다.
   - 함수호출 -> 파라미터 올리기, 함수 호출과 반환된 데이터가 저장될 레지스터만 명시한다.
   - 변수는 항상 스택 메모리에 저장된다. -> 하드웨어 의존적이므로 함수마다 할당하여 라벨화
   - 파라미터와 변수 구분한다.
   - 레지스터 -> 일단 무제한 할당한다. 오직 우항이 저장된 레지스터가 좌항보다 1을 초과하여 클때만 그 사이의 레지스터로 최적화.
   - 상수 -> 함수마다 할당. immediate load 명령어 사용한다.
   - 브랜치 -> 함수마다 무제한 할당.
   - 리턴 -> 리턴값 어딘가에 저장한다고 라벨 해놓고, 에필로그로 브랜치 
3) 명령어 셋
   - 사칙연산 (add,sub,mul,div) 사용한다. immediate사용 x
   - store, load, loadi 사용한다.
   - cmpeq(동일한지 비교), cbr(조건브랜치) 사용한다.
   - jumpi 사용한다.
